YiIME 译 — 中英翻译输入（Windows 11 x64）

0. 先用管理员 PowerShell 运行 Install-YiIME.ps1 注册系统输入法（见 TSF-使用说明.txt）。
1. YiIME.exe 是输入框和设置程序。单独双击它（或开始菜单“YiIME 设置”）只在托盘显示图标，用于打开设置；它不再提供全局快捷键。
2. 首次运行会自动打开“设置”窗口（以后可单击或右键托盘图标 → 设置…）：
   - 翻译 API 地址、模型、API 密钥：兼容 OpenAI Chat Completions 的 HTTPS 接口。
     本机 HTTP 服务可使用 http://127.0.0.1:端口 或 http://localhost:端口；局域网其他机器请配置 HTTPS。
   - 翻译风格：通用 / 专业/正式 / 口语/随意 / 学术 / 商务邮件 / 简洁。
   - 自定义要求（可选）：追加到翻译提示词，例如“使用英式拼写”。
   配置保存在 %APPDATA%\YiIME，密钥由 Windows DPAPI 加密。
3. 按 Win+空格 切换到“YiIME 译（五笔）”，在任意输入框直接打字母，文字光标旁会弹出一个小输入框。
4. 直接打五笔 86 或拼音：完整五笔码优先，拼音辅助，候选条显示在输入框下方。
   - 拼音匹配出的候选在括号里标出五笔编码（如 翻(toln)、的(r/rqyy)），帮助记码；五笔匹配出的候选不标，上屏文字不带编码。词库含 rime 五笔 86、补充的多字词与成语（约 10.6 万个多字词、3 万余条成语，编进程序），以及单独随包的白霜（rime-frost）大词库 30 万条（含 3.2 万余条四字成语，按词频排序拼音候选；GPL-3.0，见 data/README.md），多字词按标准规则取码，如 一心一意 → gngu。
   - 空格选第 1 个，数字 1～9 选对应候选，也可用鼠标点选；
   - - / = 或 PageUp / PageDown 翻页；
   - Backspace 删编码，Esc 取消当前编码，组字时 Enter 输入原始字母；
   - 拼音可用 ' 分隔音节，例如 xi'an → 西安；
   - Caps Lock 打开时或按住 Shift 打字母，直接输入英文字母（输入框没打开时直接交给应用、不弹框；输入框里原样放进草稿，正在组字时先上屏首选）；
   - 逗号、句号等标点自动转为全角（数字后的 . 和 : 保持半角）。
5. 没有在组字时：
   - Enter：调用 API 翻译草稿，并把英文直接提交到原应用（换行转为空格），输入框随即收起；
     翻译中输入框显示“翻译中…”；失败时显示错误并保留草稿。
   - Shift+Enter（或 Ctrl+Enter）：不翻译、不调用 API，直接提交中文草稿；还有未选的编码时先放入首选候选再整段提交。
   - Esc：放弃草稿并收起。
   点到别处时输入框会收起，草稿保留到下次唤出。
6. 普通五笔模式（不翻译）：Ctrl+Shift+Space（设置里可改快捷键）、托盘菜单或任务栏模式图标（译/中/英）的右键菜单切换；
   该模式下选字直接上屏，不经过草稿、不翻译。设置窗口里也可勾选。
7. 托盘图标 → 退出，结束托盘程序（不影响输入法本身）。

简拼：输入每个字拼音的首字母（至少两个）即可出词，如 yxyy → 一心一意、zgr → 中国人；zh/ch/sh 可写成 z/c/s，也可完整写出（zhgr）。排序：完整五笔码 → 完整拼音 → 简拼（按词频）→ 五笔前缀。

每页候选数：设置窗口「每页候选数（1–9）」可改，默认 9；数字键选当前页的候选，-/= 或 PageUp/PageDown 翻页。

输入记忆（回退中文窗口，设置里可开关，默认开）：
   - 每次翻译上屏都会记下中文原文、译文和时间，保存在 %APPDATA%\YiIME\history.dat（最多 500 条，只在本机，Windows DPAPI 加密）。
   - 在应用里按 Ctrl+Shift+Z（设置里可改）：光标处弹出输入框并载入上一次翻译的中文，可修改后 Enter 重新翻译，或 Shift+Enter 上屏中文。
     普通五笔模式下用这个快捷键找回时也按翻译模式处理。
   - 输入框里没有在组字、草稿为空或仍是某条记忆原文时，↑ / PageUp 看更早的记忆，↓ / PageDown 看更新的。
   - 托盘菜单「输入记忆…」列出最近的记录，可复制中文/译文，「再次使用」（或双击）把它设为下一次找回的草稿。
   - 设置窗口「清除输入记忆」删除全部记录；取消勾选输入记忆时会确认并删除已有记录，之后不再保存。
   - 注意：有些应用用 Ctrl+Shift+Z 作“重做”，本输入法启用记忆时会占用它，可在设置里换成别的组合。

微软五笔同类功能（设置窗口里可逐项开关，保存在 HKCU\Software\YiIME）：
   - 万能键 z：五笔编码中的 z 代替任意一码（如 gzzz），候选后括号标出完整编码；
   - 四码唯一时自动上屏；五码顶字（四码后继续打字母，先上屏首选）/ 空码清除（四码没有候选时丢弃）；可能是拼音时不触发；
   - ；选第二候选、' 选第三候选（可能是拼音时 ' 仍是音节分隔符）；
   - Ctrl+. 切换中/英文标点；输入框没打开时，中文标点（，。？！；：“”‘’《》【】、……——￥·～（））也直接上屏（数字后的 . 和 : 保持半角）；
   - Ctrl+Shift+F 切换简/繁输出（OpenCC 词组+单字转换）；
   - 自学习（默认关）：按选用次数调整同一编码的候选顺序，记录在 %APPDATA%\YiIME\learned.dat（加密）；
   - 用户词库：%APPDATA%\YiIME\user_words.txt，每行「词 编码」，排在该编码第一位（设置窗口「用户词库…」用记事本打开，保存后从下一次输入起生效）。

译文通过 TSF 编辑会话插入原应用。
浮动框里的字母由本程序自己组字，因此草稿框内不使用 Windows 自带输入法。
