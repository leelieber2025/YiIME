YiIME 译（五笔） — TSF 系统输入法实验版（Windows 11 x64）

此版本可注册为 Windows 中文输入法。安装前建议先建立系统还原点。
已在 Windows 11 实机上验证：弹框跟随光标、多句草稿（含 。，！？）不提前上屏、Enter 整段翻译一次上屏、Shift+Enter、Esc。

安装：
1. 解压整个 ZIP，不要只取出 EXE。
2. 用管理员身份打开 64 位 PowerShell，切换到解压目录。
3. 运行：powershell -ExecutionPolicy Bypass -File .\Install-InputTranslation.ps1
4. 安装脚本会以当前用户身份启动托盘程序，并把输入法加入当前用户的中文输入法列表。
   用 Win+空格 选择「YiIME 译（五笔）」。如未出现，注销再登录，或在 设置 → 时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 添加键盘 中添加。

使用：
1. 在目标应用的普通文本框中打第一个字母，光标旁会弹出一个小输入框（浮动、无边框），首字母已进入编码。
   输入框会贴着目标应用的文字光标显示；下方放不下时显示在光标上方。启动期间继续打的字母会缓存并补进编码。
2. 继续打五笔 86 或拼音编码，候选条显示在输入框下方：空格选第 1 个，数字 1～9 选对应项，
   - / = 或 PageUp / PageDown 翻页，Esc 取消编码，组字时 Enter 输入原始字母，拼音可用 ' 分隔音节。
   拼音匹配出的候选在括号里标出五笔编码（如 翻(toln)、的(r/rqyy)），帮助记码；五笔匹配出的候选不标，上屏文字不带编码。词库含 rime 五笔 86、补充的多字词与成语（约 10.6 万个多字词、3 万余条成语，编进程序），以及单独随包的白霜（rime-frost）大词库 30 万条（含 3.2 万余条四字成语，按词频排序拼音候选；GPL-3.0，见 data/README.md），多字词按标准规则取码，如 一心一意 → gngu。
3. 选好的字和标点（，。！？等）都留在输入框里的中文草稿，可连续输入多句；草稿超过约 480 像素自动换行、输入框增高。
   选字和标点都不会翻译或上屏。草稿可用方向键、Backspace 调整，也可粘贴。
4. 没有在组字时按 Enter：翻译草稿并把英文直接通过 TSF 编辑会话插入原应用，输入框收起。
   翻译中显示“翻译中…”，失败时显示错误并保留草稿。Shift+Enter（或 Ctrl+Enter）直接插入中文草稿，不翻译、不调用 API；还有未选的编码时先放入首选候选。
5. Esc（没有在组字时）放弃草稿并收起；点到别处会收起，草稿保留到下次唤出。
6. 翻译 API、翻译风格、自定义要求在“设置”窗口填写：单击或右键任务栏托盘里的「YiIME 译」图标 → 设置…，或开始菜单「YiIME 设置」。
   未配置时按 Enter 会自动打开设置窗口。配置保存在 %APPDATA%\InputTranslation，密钥由 Windows DPAPI 加密。
7. 切换到本输入法时默认是中文模式。任务栏输入法图标（橙色“译”）旁显示“译/中/英”，单击它、单独按一下 Shift（像微软拼音）或按 Ctrl+Space 切换；
   英文模式下字母直接上屏、不弹出输入框、不翻译。按住 Shift 打字母（大写）不会切换。
   中文模式下 Shift+字母直接输入大写字母（输入框没打开时直接交给应用、不弹框；输入框里则原样放进草稿，正在组字时先上屏首选）；
   Caps Lock 打开时所有字母都按原样输入、不组字（翻译模式和普通五笔模式相同）。
   浮动框打开时按 Shift 不切换模式，草稿和编码保持不变。
   密码输入范围和禁用上下文会放行按键。
   普通五笔模式（不翻译）：按 Ctrl+Shift+Space（可在设置里改）、任务栏模式图标（译/中/英）右键菜单，或托盘菜单「普通五笔模式（不翻译）」切换。
   该模式下像普通五笔输入法：空格/数字选字后直接上屏，不经过草稿、不翻译；组字时 Enter 上屏字母，Esc 取消。
   任务栏按钮显示：译 = 翻译模式，中 = 普通五笔模式，英 = 英文；托盘提示也显示当前模式。单独按 Shift 在两种模式下都切换中/英。
8. 编辑器进程在同一输入法会话中复用；托盘菜单「退出」会关闭它。宿主应用退出时编辑器也会自动退出。
   编辑器 5 秒内没有就绪时，输入法会结束它，并把已缓存的字母还给原应用。
9. 请专门测试：连续输入两句、输入框弹出位置（记事本、浏览器、Word）、点到别处后再打字能否重新弹出、
   Ctrl+Space 切换、密码框输入，以及编辑器无响应时的恢复。
10. 翻译 API 默认要求 HTTPS；仅本机回环地址允许 HTTP，局域网其他机器请配置 HTTPS。

任务栏模式图标（v10 起）：
   - 右下角输入指示器在品牌图标左边显示模式：译 = 翻译模式，中 = 普通五笔模式，英 = 英文。左键单击或单按 Shift 切换中/英。
   - 右键模式图标弹出菜单：中文/英文、翻译模式/普通五笔模式、中文标点、繁体输出、输入记忆…、设置…。
   - 诊断日志：%TEMP%\YiIME-tsf.log（输入法激活、模式按钮加入、Shift 切换、菜单选择等；不记录打字内容）。

简拼：输入每个字拼音的首字母（至少两个）即可出词，如 yxyy → 一心一意、zgr → 中国人；zh/ch/sh 可写成 z/c/s，也可完整写出（zhgr）。排序：完整五笔码 → 完整拼音 → 简拼（按词频）→ 五笔前缀。

每页候选数：设置窗口「每页候选数（1–9）」可改，默认 9；数字键选当前页的候选，-/= 或 PageUp/PageDown 翻页。

输入记忆（回退中文窗口，设置里可开关，默认开）：
   - 每次翻译上屏都会记下中文原文、译文和时间，保存在 %APPDATA%\InputTranslation\history.dat（最多 500 条，只在本机，Windows DPAPI 加密）。
   - 在应用里按 Ctrl+Shift+Z（设置里可改）：光标处弹出输入框并载入上一次翻译的中文，可修改后 Enter 重新翻译，或 Shift+Enter 上屏中文。
     普通五笔模式下用这个快捷键找回时也按翻译模式处理。
   - 输入框里没有在组字、草稿为空或仍是某条记忆原文时，↑ / PageUp 看更早的记忆，↓ / PageDown 看更新的。
   - 托盘菜单「输入记忆…」列出最近的记录，可复制中文/译文，「再次使用」（或双击）把它设为下一次找回的草稿。
   - 设置窗口「清除输入记忆」删除全部记录；取消勾选输入记忆时会确认并删除已有记录，之后不再保存。
   - 注意：有些应用用 Ctrl+Shift+Z 作“重做”，本输入法启用记忆时会占用它，可在设置里换成别的组合。

微软五笔同类功能（设置窗口里可逐项开关，保存在 HKCU\Software\InputTranslation）：
   - 万能键 z：五笔编码中的 z 代替任意一码（如 gzzz），候选后括号标出完整编码；
   - 四码唯一时自动上屏；五码顶字（四码后继续打字母，先上屏首选）/ 空码清除（四码没有候选时丢弃）；可能是拼音时不触发；
   - ；选第二候选、' 选第三候选（可能是拼音时 ' 仍是音节分隔符）；
   - Ctrl+. 切换中/英文标点；输入框没打开时，中文标点（，。？！；：“”‘’《》【】、……——￥·～（））也直接上屏（数字后的 . 和 : 保持半角）；
   - Ctrl+Shift+F 切换简/繁输出（OpenCC 词组+单字转换）；
   - 自学习（默认关）：按选用次数调整同一编码的候选顺序，记录在 %APPDATA%\InputTranslation\learned.txt；
   - 用户词库：%APPDATA%\InputTranslation\user_words.txt，每行「词 编码」，排在该编码第一位（设置窗口「用户词库…」用记事本打开，重新唤出输入框后生效）。

输入法 DLL 与 EXE 会安装到 Program Files\InputTranslation 的版本目录；升级时保留仍被应用占用的旧版文件。
如需卸载，以管理员身份运行：powershell -ExecutionPolicy Bypass -File .\Uninstall-InputTranslation.ps1
卸载默认保留当前用户的 API 配置和输入记忆。若要一并删除（含 HKCU\Software\InputTranslation 里的开关），加参数 -RemoveSettings。

已知边界：这是首次 TSF 集成版本，需在记事本等普通控件先验证。某些游戏、管理员权限应用、32 位应用和不同 TSF 宿主尚未验证；
每个使用本输入法的应用会各有一个编辑器进程，因此托盘里可能同时出现多个「YiIME 译」图标。如出现异常，请切回原输入法并运行卸载脚本。
